# REJİ

Dört kanallı YouTube yayın masası.

Brief, başlık, kanca, senaryo, çekim listesi, kapak, görsel/video promptu, yayın paketi ve kontrol listesi. Kanal profili kapağı ve görsel stilini belirler. Kayıtlar tarayıcıda durur; dışa ve içe aktarma JSON’dur.

Hazır kanallar: bilimcifikri, mitocolik, Bir Kitabın Anatomisi, Papi Pupa.

```bash
npm install
npm run dev
```
